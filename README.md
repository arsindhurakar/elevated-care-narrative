# Dr. Sony Sherpa - Obstetrician & Gynecologist

A professional portfolio website for **Dr. Sony Sherpa**, an Obstetrician & Gynecologist, showcasing her professional experience, expertise, education, and approach to patient care.

## About

This website presents Dr. Sony Sherpa's professional profile and provides visitors with information about her medical expertise, experience, and services.

## Tech Stack

* **Next.js 16** - React framework
* **React 19** - UI library
* **TypeScript** - Type-safe development
* **Tailwind CSS 4** - Styling and responsive design
* **shadcn/ui** - UI components
* **Lucide React** - Icons
* **ESLint** - Code quality and linting
* **Vercel** - Deployment

## Getting Started

Clone the repository:

```bash
git clone https://github.com/arsindhurakar/elevated-care-narrative.git
```

Navigate to the project directory:

```bash
cd elevated-care-narrative
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Available Scripts

### Development

```bash
npm run dev
```

Starts the development server.

### Production Build

```bash
npm run build
```

Creates an optimized production build.

### Production

```bash
npm run start
```

Starts the production server.

### Lint

```bash
npm run lint
```

Runs ESLint to check the codebase.
